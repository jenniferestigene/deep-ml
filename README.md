## About Deep-ML

[Deep-ML](https://www.deep-ml.com/) is a free, open-source platform for learning
machine learning and deep learning through problem solving, in the spirit of
LeetCode for ML. Rather than reading about an algorithm, you implement it
directly: each problem asks you to write the function from scratch in Python,
covering linear algebra, statistics and probability, calculus, classical
machine learning, deep learning, natural language processing, computer vision,
and reinforcement learning. Solutions run in-browser against hidden test cases,
so correctness is checked immediately rather than assumed. The problem bank
itself is community-maintained and open source, with new challenges added by
machine learning practitioners and educators rather than a fixed curriculum.
